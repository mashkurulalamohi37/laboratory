# API Specification (contract overview)

Base: `/api/v1`. JSON over HTTPS. The **OpenAPI document generated by FastAPI is the source of truth**. This file defines conventions and the endpoint inventory, and each phase fills in schemas and examples in code (Pydantic `model_config["json_schema_extra"]`).

## 1. Conventions

**Envelope — success**
```json
{ "success": true, "data": { ... }, "meta": { "request_id": "01J…", "page": 1, "page_size": 20, "total": 134 } }
```
**Envelope — error**
```json
{ "success": false,
  "error": { "code": "BOOKING_SLOT_UNAVAILABLE", "message": "The selected time slot is no longer available.",
             "details": [{ "field": "slot_id", "issue": "full" }], "request_id": "01J…" } }
```

| HTTP | Typical codes |
|---|---|
| 400 | `VALIDATION_ERROR` (details per field) |
| 401 | `AUTH_REQUIRED`, `TOKEN_EXPIRED`, `OTP_INVALID`, `OTP_EXPIRED` |
| 403 | `PERMISSION_DENIED`, `SCOPE_DENIED` |
| 404 | `NOT_FOUND` (also returned instead of 403 when existence itself is sensitive) |
| 409 | `INVALID_STATE_TRANSITION`, `BOOKING_SLOT_UNAVAILABLE`, `IDEMPOTENCY_KEY_REUSED`, `VERSION_CONFLICT` |
| 422 | `COUPON_NOT_APPLICABLE`, `PAYMENT_AMOUNT_MISMATCH`, business-rule failures |
| 429 | `RATE_LIMITED` (+ `Retry-After`) |
| 500 | `INTERNAL_ERROR` (no internals leaked) |

- **Pagination:** `?page=&page_size=` (≤ 100) for admin tables; `?cursor=` for feeds and logs.
- **Filtering and sorting:** `?filter[field]=value`, `?sort=-created_at,name`.
- **Idempotency:** `Idempotency-Key: <uuid>` is **required** on `POST /bookings`, `POST /payments`, `POST /refunds` and `POST /bookings/{id}/confirm-cash`.
- **Concurrency:** `If-Match: <version>` on PATCH of versioned resources → `409 VERSION_CONFLICT`.
- **Localisation:** `Accept-Language: bn|en` selects localised fields. Money is returned as `{ "amount": 150000, "currency": "BDT", "display": "৳1,500" }`.
- **Auth notation below:** 🌐 public · 👤 authenticated patient · 🔑 permission code(s).

## 2. Endpoint inventory

### Auth
| Method | Path | Auth |
|---|---|---|
| POST | `/auth/send-otp` `{phone, purpose: LOGIN|REGISTER|RESET|REPORT}` | 🌐 (rate-limited) |
| POST | `/auth/verify-otp` → tokens (creates the user on first login) | 🌐 |
| POST | `/auth/login` `{identifier, password}` → tokens, or a `{two_factor_required, challenge_id, phone_hint}` challenge for staff | 🌐 |
| POST | `/auth/2fa/verify` `{challenge_id, code}` → tokens | 🌐 |
| POST | `/auth/refresh` (web: HttpOnly cookie; mobile: `{refresh_token}`) | 🌐 (token) |
| POST | `/auth/logout` · `/auth/logout-all` | 👤 |
| POST | `/auth/logout-cookie`: revoke via the refresh cookie when the access token has already expired | 🌐 (cookie) |
| POST | `/auth/password/forgot` · `/auth/password/reset` · `/auth/password/change` | 🌐 / 👤 |
| GET/DELETE | `/auth/sessions`, `/auth/sessions/{id}` | 👤 |
| GET / PATCH | `/me`: profile, role grants with scopes, effective permissions; PATCH updates name and preferred language | 👤 |

**Implemented in Phase 1:** everything in this Auth table, plus admin `users` (list/create staff/get/status), `users/{id}/roles` (grant/revoke), `roles` (list, `PUT /roles/{code}/permissions`), `permissions`, `audit-logs` (read-only), and `/health` `/live` `/ready` `/metrics`. The generated OpenAPI document (`/api/docs`) is authoritative.

### Admin (console) 🔑 — standard CRUD resource pattern
`GET /admin/{resource}` (list, filters, export `?format=csv`) · `POST` · `GET /{id}` · `PATCH /{id}` · `DELETE /{id}` (soft; config data only) · `POST /admin/{resource}/import`

Resources: `users, roles, permissions, patients, doctors, pathologists, technicians, collectors, tests, test-categories, test-departments, parameters, reference-ranges, sample-types, packages, health-concerns, price-lists, centres, branches, labs, zones, slot-templates, holidays, bookings, collections, samples, coupons, payments, invoices, refunds, partners, commission-rules, corporates, inventory-items, inventory-batches, stock-movements, suppliers, purchase-orders, expenses, cms/pages, cms/banners, cms/blogs, cms/faqs, cms/testimonials, cms/promotions, notification-templates, support/tickets, settings, audit-logs (read-only)`

Plus: `GET /admin/dashboard/summary`, `GET /admin/analytics/{metric}?from=&to=&group_by=`.

### Ops
`GET /health`, `/live`, `/ready` (outside `/api/v1`, not rate-limited, no auth) · `GET /metrics` (internal network only).
